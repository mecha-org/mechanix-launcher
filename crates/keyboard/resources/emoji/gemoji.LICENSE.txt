Emoji shortcodes and keywords for emoji suggestions (typing ":smil" offers 😄).

Source: GitHub gemoji, db/emoji.json
(https://github.com/github/gemoji/blob/ee6e06c648e85d601756b573d356327d4e51031d/db/emoji.json,
downloaded from
https://raw.githubusercontent.com/github/gemoji/ee6e06c648e85d601756b573d356327d4e51031d/db/emoji.json;
ee6e06c648e85d601756b573d356327d4e51031d is the last commit to change the file,
2023-03-29). Licensed under the MIT License below, per the repository's LICENSE
file.

gemoji.json.gz is that file gzipped (gzip -9 -n) and otherwise unmodified
(SHA-256 of the uncompressed file
b174ae2aeb321b52f64adb9ff412f966a7f338839d780784dd15dcad702c2dd6).
build.rs compiles it into the searchable form the keyboard embeds; see
src/dictionaries/emoji/compile.rs.
